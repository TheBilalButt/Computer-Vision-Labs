# Lab 01: OpenCV Fundamentals and Image Processing Basics

## Overview
This laboratory assignment introduces core foundational concepts of Computer Vision and digital image processing using Python and OpenCV.

## Objectives
- Load, inspect, and display digital images across various formats.
- Understand RGB, BGR, Grayscale, HSV, and LAB color spaces.
- Perform channel splitting, merging, and color manipulation.
- Execute basic geometric operations: resizing, cropping, rotation, and translation.
- Analyze pixel intensity distributions using image histograms.
- Apply global and adaptive thresholding techniques.

## Key Implementations
- **Notebook:** `Lab01_OpenCV_Fundamentals.ipynb`
- **Dependencies:** `opencv-python`, `numpy`, `matplotlib`

## Quick Start
```bash
pip install opencv-python numpy matplotlib
jupyter notebook Lab01_OpenCV_Fundamentals.ipynb
```
