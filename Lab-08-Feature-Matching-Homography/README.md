# Lab 08: Feature Matching and Homography Estimation

## Overview
This laboratory assignment explores advanced feature matching, geometric transformation estimation, and planar homography computation using OpenCV.

## Objectives
- Extract local descriptors using SIFT, ORB, and AKAZE.
- Perform descriptor matching using Brute Force Matcher and FLANN.
- Implement Lowe's ratio test to filter false matches.
- Compute perspective Homography matrices via RANSAC.
- Apply planar transformation to align and stitch source images.

## Key Files
- **Notebook:** `Lab08_Feature_Matching_Homography.ipynb`
- **Dependencies:** `opencv-python`, `numpy`, `matplotlib`
